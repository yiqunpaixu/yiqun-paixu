# 意群排序

通过「先听原句 → 排列意群 → 复听巩固」练习英语听力。将听到的句子与文字、场景配图对应，帮助理解句子结构和表达含义。

本仓库提供网站的静态运行文件，可用于 GitHub Pages，也可完整下载后在本地打开。

文档更新：2026-10-24；本运行包对应 v1.6.7，包含120篇完整练习和配图。线上内容以实际部署版本为准。

**网站入口：** [意群排序在线体验](https://yiqunpaixu.github.io/yiqun-paixu/)（实际地址以仓库 Settings → Pages 显示为准）。

## 功能

- **逐句精听**：使用文章录音中的原句，完成首听后显示练习卡片。
- **意群排序**：按照听到的顺序点击卡片；排列错误后可重新练习。
- **三档切分**：概览、标准、详细；在排列阶段切换，保持当前句子。
- **辅助理解配图**：以场景线索帮助理解；120 篇／1897 句均有整句配图，具体含义和限定仍须听音确认。
- **复听巩固**：完成排列后展示完整原句并复听，随后自动进入下一句。
- **完成后全文复听**：使用与首页相同的全文播放面板，展开原文并点击单句重听。
- **随机推荐**：根据本浏览器保存的练习表现调整篇章出现概率。
- **学习记录**：查看已练句子、独立排对、排错、辅助记录、熟练度参考、推荐权重，以及按实际音频播放累计的总学习时间和每篇时间。

当前运行版本为 **1.6.7**，工作区包含 **15 套录音、120 篇文章、1897 个句子任务**，覆盖新闻、对话与短文。三档切分为概览、标准、详细；新增语料的切分与音频时间仍须继续复核。

> 熟练度是练习表现的参考指标，不代表标准化英语能力测评结果；排序正确也不等于已经能够在无文字、无配图的情况下听懂原句。

## 使用方法

1. 在首页选择随机推荐篇章，或展开「全部篇章」选择文章。
2. 点击「开始这篇」。普通篇章入口每次从第一句开始，已有学习成绩仍保留。
3. 点击播放，先听完整原句；首听结束后显示卡片。
4. 按听到的顺序点击卡片。只有一张卡片时，也需要点击确认。
5. 排列完成后复听原句，程序自动进入下一句；完成整篇后，可在与首页相同的面板播放全文、点击「查看原文」展开全文并点任一句重听，或返回首页。全文播放到篇尾停止；暂停后再次播放会从篇首开始，返回首页会停止音频。

排列阶段每组自动循环最多 **5 次**，随后暂停；手动点击播放可开始新一组。首听与完成后的巩固复听不计入这五次。

浏览器可能限制自动播放，首次使用请主动点击播放按钮，并确认设备音量已开启。

## 学习记录与隐私

- 学习记录保存在当前浏览器的 **localStorage** 中。本版本没有账号、学习成绩上传接口或云端同步功能。
- 刷新、关闭后重新打开网站，通常仍能读取记录；清除站点数据、使用无痕模式或浏览器存储被限制时，记录可能无法保留。
- 不同设备、浏览器及浏览器用户配置不自动共享记录。
- 不同协议、域名或端口使用不同的存储空间；本地记录不会自动转移到 GitHub Pages 或自定义域名。
- 在同一网址来源更新网站文件，保持存储格式和任务身份兼容时，已有记录通常保留。
- 学习记录目前没有通用导出、备份或恢复功能。同一浏览器配置下多人使用同一网站，会共用记录。

这些说明针对应用的学习数据处理。网站托管平台的访问日志及其他数据处理，由平台自己的隐私政策说明。

学习时间计入首听、循环、巩固复听、全文与单句重听，重复播放累计，并按实际播放速度折算；暂停、加载等待、静音和跳转距离不计。只记录启用功能后的播放，旧学习时间未知，不根据已练句数推算；时间不改变熟练度或推荐权重。

## 本地运行

1. 下载仓库 ZIP 或网站运行包。
2. **完整解压**，保留 `data/`、`assets/` 和其他配套文件。
3. 双击解压目录中的 `index.html`。

无需安装 Node.js，也不需要修改浏览器安全设置。不要直接在压缩包预览中打开 HTML，或只复制 `index.html`。

本地文件模式通过配套的数据脚本按篇加载。浏览器对本地文件的存储行为存在差异，移动文件夹后不保证沿用旧记录；长期使用可通过固定的 HTTP／HTTPS 地址访问。

## GitHub Pages 部署

1. 将运行文件放在仓库根目录，确保根目录直接包含 `index.html`、`.nojekyll`、`data/` 和 `assets/`。
2. 打开 **Settings → Pages**。
3. Source 选择 **Deploy from a branch**。
4. Branch 选择 **main**，目录选择 **/(root)**，点击 **Save**。
5. 等待 Pages 部署完成，再通过 **Visit site** 打开网站。

后续更新使用新导出的完整运行文件，保留 `.nojekyll` 和配套目录；在同一网站来源保持存储格式和任务身份兼容，可继续读取已有记录。网页上传每次最多 100 文件、单文件 25 MiB；大量素材可用 GitHub Desktop 或 Git 上传，见 [GitHub 上传说明](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)。

这是纯静态版本，HTTP 模式按篇读取 JSON。GitHub Pages 不运行 Node 服务；仓库和网站公开后，运行代码、语料、图片和音频可被获取，按篇加载不构成素材访问权限保护。

本包音频为原始录音的按篇MP3压缩副本，保持句子时间与篇章范围；不是合成语音。
